Política de Privacidad

Última actualización: 3/09/2026

Esta Política de Privacidad describe cómo agente_personal ("el Asistente", "nosotros") recolecta, usa y protege la información de las personas que interactúan con el asistente personal a través de WhatsApp u otros canales conectados.

El Asistente es una herramienta personal de inteligencia artificial que ayuda a sus usuarios a:

  • Practicar y aprender inglés mediante conversación y correcciones
  • Llevar seguimiento de una rutina de ejercicio
  • Organizar y reforzar hábitos y contenidos de estudio

1. Información que recolectamos

  • Mensajes enviados al asistente: texto (y opcionalmente audio) que el usuario escribe o envía durante la conversación.
  • Identificador de contacto: número de teléfono o ID de usuario de WhatsApp, usado únicamente para responder dentro de la misma conversación.
  • Datos de progreso: nivel de inglés, errores frecuentes, ejercicios completados, rutinas de ejercicio registradas y notas de estudio, con el fin de personalizar la experiencia.
  • Metadatos técnicos: marcas de tiempo de los mensajes, para poder ordenar el historial de la conversación.

2. Cómo usamos la información

  • Para generar respuestas personalizadas y relevantes a través de modelos de inteligencia artificial (por ejemplo, servicios de OpenAI o Anthropic).
  • Para llevar un registro del progreso del usuario en inglés, ejercicio y estudio, y así adaptar el contenido con el tiempo.
  • Para mejorar el funcionamiento del asistente (ej. detectar errores frecuentes o fallas en las respuestas).

No utilizamos la información para publicidad ni la vendemos a terceros.

3. Con quién compartimos la información

Para funcionar, el Asistente envía los mensajes del usuario a proveedores externos de inteligencia artificial (por ejemplo, OpenAI y/o Anthropic) con el único fin de generar una respuesta. Estos proveedores procesan la información conforme a sus propias políticas de privacidad y no la utilizan para identificar al usuario fuera de este contexto.

Los datos de progreso (nivel, errores, rutinas, notas) se almacenan en una base de datos privada (por ejemplo, Postgres, Airtable o Google Sheets, según corresponda) utilizada exclusivamente para el funcionamiento del propio Asistente.

No compartimos información con anunciantes ni con terceros ajenos al funcionamiento del servicio.

4. Almacenamiento y seguridad

La información se conserva mientras el usuario continúe usando el Asistente, con el fin de mantener el historial de progreso. Se toman medidas razonables para proteger los datos contra accesos no autorizados, aunque ningún sistema es 100% infalible.

5. Derechos del usuario

El usuario puede en cualquier momento:

  • Solicitar acceso a los datos que se han almacenado sobre él/ella.
  • Solicitar la eliminación total de su historial y datos de progreso.
  • Dejar de usar el servicio en cualquier momento, simplemente dejando de interactuar con el número/canal correspondiente.

Para ejercer estos derechos, puede escribir directamente al canal de contacto indicado abajo.

6. Menores de edad

Este servicio no está dirigido a menores de 13 años. Si eres padre, madre o tutor y crees que un menor ha usado el servicio sin tu consentimiento, contáctanos para eliminar la información correspondiente.

7. Cambios a esta política

Esta política puede actualizarse ocasionalmente. La fecha de la última actualización se indica al inicio de este documento.
